Hash Router

İnternetin ilk yıllarında, sayfa içinde hızlı yönlendirmeler yapabilmek çapa linkler oluşturabilmek için yapılmış bir özelliktir. Taraycı yeniden yüklenmeden sunucuya istek atılmadan sayfa içi linke gidilir. Tarayıcı bunu tamamen kendi içinde yönetir. 



  https://example.com/#about
  https://example.com/#about
  
<a href="#about">Hakkımızda Git

Peki SPA'lar bunu neden kullanmaya başladı?

JavaScript gelişmeye başlayınca geliştiriciler şunu fark etti:

Hash değişince #/about #/contact sayfa yenilenmiyor. Bunu fırsata çevirdiler. Dediler ki

"Hash değişince yeni component gösterelim."

Böylece ilk SPA routing mantığı ortaya çıktı. Örneğin 


      https://example.com/#/about

      olunca JavaScript

      if(location.hash == "#/about"){
          // About sayfasını göster
      }
Vue'da karşılığı

createWebHashHistory()

History API

HTML5 History API, web sayfasını yeniden yüklemeden tarayıcının adres çubuğundaki URL'yi değiştirmeyi ve tarayıcının ileri/geri geçmişini programatik olarak yönetmeyi sağlayan, HTML5 ile standartlaştırılmış bir tarayıcı özelliğidir. Bu özellik JavaScript aracılığıyla kullanılır.


HTML5 History API olmadan           HTML5 History API sayesinde ise
      Tıklama                               example.com
        ↓                                       ↓
      Sunucu                              example.com/about
        ↓                           URL değişir fakat sayfa yenilenmez.
    Yeni HTML                            Sadece JavaScript çalışır.
        ↓
Sayfa tamamen yenilenir

SPA (Single Page Application) yapısını mümkün hale getirmektir.

History API'nin 5 temel metodu vardır.

  1. history.pushState()
  2. history.replaceState()
  3. history.back()
  4. history.forward()
  5. history.go()

1-) pushState()

En çok kullanılanıdır. Yeni bir URL ekler. Örneğin:


  history.pushState({}, '', '/about')

  /
  ↓
  /about

  url değişir ama sayfa yenilenmez.

2-) replaceState()

URL'yi değiştirir. Ama geçmişe eklemez.


  history.replaceState({}, '', '/login')

3-) back()

Tarayıcıdaki ← tuşunun aynısıdır.


  history.back()

4-) forward()

İleri git


  history.forward()

5-) go()

İstenilen kadar ileri geri gider.


  history.go(-1)  // Bir önceki sayfa
  history.go(-2)  // İki önceki sayfa
  history.go(1)   // Bir ileri
