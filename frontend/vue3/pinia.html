Pinia Notları

defineStore

Tabii. defineStore, Pinia'da bir store (merkezi state alanı) oluşturmak için kullanılan temel fonksiyondur.


defineStore(id, setupFunction) iki parametre alır 
1. parametre storeun id sidir nerede kulanılacağnı anlatan bir tanımlama yapılabilinir.
1. paramtre ise fonksiyonların içerisinde olduğu e callback fonksiyondur.

defineStore(id, setupFunction)

--------------------------

import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useCounterStore = defineStore('counter', () => {

  // State
  const count = ref(0)

  // Getter
  const doubleCount = computed(() => {
    return count.value * 2
  })

  // Action
  function increment() {
    count.value++
  }

  // Dışarı açılanlar
  return {
    count,
    doubleCount,
    increment
  }

})

storeToRefs

storeToRefs(), Pinia store'daki state ve computed 'ları destructure ederken reaktifliği korumak için kullanılır. fonksiyonlar ise doğrudan store'dan alınır. 



import { useCounterStore } from '@/stores/counter'
import { storeToRefs } from 'pinia'

const counterStore = useCounterStore()

const { count, doubleCount } = storeToRefs(counterStore)
