Vue Router

createRouter

Tabii. createRouter, Vue Router'ın ana router nesnesini oluşturduğumuz fonksiyondur.

Açıkçası projelerin %95'inde yalnızca bunlar kullanılır:history,routes, scrollBehavior() 


import {
  createRouter,
  createWebHistory
} from 'vue-router'

import HomeView from '@/views/HomeView.vue'
import AboutView from '@/views/AboutView.vue'

const router = createRouter({
  // History modu
  history: createWebHistory(),

  // Tüm route'lar
  routes: [
    {
      path: '/',
      name: 'home',
      component: HomeView
    },
    {
      path: '/about',
      name: 'about',
      component: AboutView
    }
  ],

  // Sayfa değişince scroll davranışı
  scrollBehavior(to, from, savedPosition) {
    if (savedPosition) {
      return savedPosition
    }

    return {
      top: 0
    }
  },

  // RouterLink aktif olduğunda eklenecek class
  linkActiveClass: 'active',

  // URL tamamen eşleştiğinde eklenecek class
  linkExactActiveClass: 'exact-active',

  // Route parse/stringify işlemleri
  parseQuery(search) {
    return Object.fromEntries(new URLSearchParams(search))
  },

  stringifyQuery(query) {
    const params = new URLSearchParams(query)
    return `?${params.toString()}`
  }
})

export default router

routes Nesnesi

routes Vue Router'ın en önemli özelliğidir. Çünkü uygulamadaki tüm sayfaların (rotalar) tanımlandığı bir dizidir.

Bir Route Nedir ? Route Record Nedir ?

Bu URL'ye gidildiğinde hangi component gösterilecek? gibi tanımlamalaırn yapıldığı routes dizisi içerisindeki her bir neyseneye route denir. Bu tanımlama işleminede Route Record denir. 


  const router = createRouter({
    routes: [
      {
        path: '/',
        component: HomeView
      }
    ]
  })

Route Record içinde neler olabilir?

Aşşağıdaki Özellikler En Çok Kullanılan Özelliklerdir.


{
    path: '/',                // URL'yi belirtir.
    name: 'home',             // Route'a isim verir.
    component: HomeView,      // Hangi Vue componentinin gösterileceğini belirtir.
    children: [               // İç içe sayfalar oluşturur.
      {
          path: 'users',
          component: Users
      },
      {
          path: 'products',
          component: Products
      }
    ]
  meta: {                             // Ek bilgiler saklanır. Daha sonra Route Guard içinde kullanılabilir.
      requiresAuth: true
    }
    beforeEnter(to, from, next) {     //Sadece o route için çalışan Guard'dır.
      next();
    }
    redirect: '/login',               //  Başka sayfaya yönlendirir.  Kullanıcı / adresine gelince otomatik /home açılır.
    alias: '/anasayfa'                // Aynı sayfanın birden fazla adresi olur. / ve /anasayfa aynı componenti gösterir.
}

useRouter()

useRouter(), Vue Router'ın router nesnesine erişmeni sağlayan composable'ıdır. "Router'ı JavaScript içinde kullanarak yönlendirmeler yapabilmemizi sağlayan fonksiyondur."<
Yönlendirme yapmak için gidilecek sayfayı belirlemek için kullanılır. 


<script setup>
import { useRouter } from 'vue-router'

const router = useRouter();
router.push('/about')
router.back()
router.forward()


</script>

useRoute

useRoute(), o an bulunduğu sayfanın (route'un) bilgilerini okumak için kullanılır. "Mevcut URL'nin bilgilerini verir." 



<script setup>
import { useRoute } from 'vue-router'

const route = useRoute()

route.path	        Mevcut URL yolu
route.params	      URL parametreleri
route.query	        Query string verileri
route.name	        Route adı
route.fullPath    	Tam URL (/products?page=2)

</script>

RouterLink

Vue Router'da sayfalar arasında geçiş yapmak için kullanılan bileşendir. a etiketi yerine sayfayı yenilemeden url değiştirmeyi mümkün kılar 



<a href="/about">Hakkımızda
<RouterLink to="/about">Hakkımızda

router.push()

router.push() JavaScript üzerinden programatik olarak sayfa değiştirmek için kullanılır.



<script setup>
import { useRouter } from 'vue-router'

const router = useRouter()

function goAbout() {
  router.push('/about') sayfasına gider.
}

function goContact() {
  router.push({name: 'contact'}) name ile gitme
}

function goProductDetail() {  Parametre gönderme
  router.push({                 /product/15
    name: 'product',
    params: {
      id: 15
    }
  })
}

function goReviewDetail() {  Query gönderme
  router.push({              /products?category=phone&page=2
    name: 'review',
    query: {
      category: 'phone',
      page: 2
    }
  })
}

</script>

<template>
  <button @click="goAbout">
    Hakkımızda Git
  </button>
</template>
